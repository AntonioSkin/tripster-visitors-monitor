# Задача 3: история всего календаря 57434

Ежедневно первый успешный замер после 08:00 по Алматы. Повторные попытки каждый час, резервный запуск из Daily visitors. GitHub может задерживать расписание. Ручной запуск доступен в Actions; успешный дневной замер не перезаписывается.

Читается весь календарь до `end` ответа Tripster, без фиксированного ограничения 30 днями или шестью месяцами. Каждая новая дата и время получает неизменный начальный остаток при первом наблюдении. Архив прошедших дат сохраняется.

Файлы: `data/calendar_history/57434/daily/YYYY-MM-DD.json` (исходные ежедневные снимки), `history.csv` (все замеры), `summary.csv` (последний замер каждого выезда, включая прошедшие), `latest.txt` (сводка). CSV открываются в Excel и импортируются в Google Таблицы; автоматической синхронизации с Google нет.

Чистое уменьшение за сутки = вчерашний остаток минус сегодняшний; если вчерашнего наблюдения нет, поле пустое. Накопительное = первый остаток минус текущий. Отрицательные значения означают увеличение. Это не точные продажи: отмены и изменения вместимости неотличимы от покупок по одному остатку. Пропавшие даты/выезды не считаются нулём, а отмечаются `not_published`. Явный ноль сохраняется.

Один отчёт в Telegram в сутки; подтверждённая отправка записывается отдельно. При ошибке отправки повтор использует уже сохранённый снимок, не меняя начальные значения. Если сообщение принято Telegram, но ответ или git push потерян, возможен дубль. Ошибки не перезаписывают старые снимки.
