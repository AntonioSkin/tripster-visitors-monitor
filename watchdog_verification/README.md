# Проверка реального Cloudflare запуска и восстановления

`runtime-test.mjs` воспроизводит ошибки `Illegal invocation` и неподдерживаемого
режима `redirect:error` в настоящем workerd. Проверяет исправленный вызов
GitHubClient и отказ при переадресации. Все запросы перехватывает
локальный тестовый сервис: ключи и внешний сетевой доступ не используются.

Эти файлы не меняют семь рабочих мониторингов и конфигурацию основного Worker.

1. `Verify external watchdog observation` проверяет реальные bindings, режим
   observe, пустой allowlist, отсутствие публичного URL и правильный Cron. Затем
   подключается к Cloudflare Tail и ожидает реальное событие scheduled с отчётом
   по семи задачам. Ошибки чтения не считаются успешной проверкой.
2. Отдельный workflow `Isolated watchdog recovery canary` создаёт только
   одноразовый тестовый artifact. Его job `save` намеренно завершается ошибкой
   на первой попытке. Нет Telegram, Healthchecks и записи в данные мониторингов.
3. Только после успешного подтверждения наблюдения запускается
   `Test isolated Cloudflare recovery`. Он поднимает временный Worker
   `tripster-watchdog-recovery-test` со своим SQLite Durable Object и расписанием
   раз в минуту. Разрешён только точный canary workflow, main и проверенный SHA.
4. Worker использует общий `restoreAction` из основного контролёра и повторяет
   только `save` job. Резерв попытки записывается до POST; повтор при неизвестном
   результате не допускается. Проверка требует, чтобы collector job ID остался
   прежним, а исходный artifact успешно проверился на повторном save.
5. В конце всегда убираются Cron тестового Worker и его копия GitHub-ключа.
   Основной наблюдатель продолжает работать. Сам тестовый Worker и его SQLite
   доказательство сохраняются без активного расписания и без GitHub-ключа.

Выводятся только безопасные результаты проверки, идентификаторы заданий и
состояние семи задач. API-ключи, адрес Tail WebSocket и необработанные сообщения
сервера не записываются в результаты. Артефакты проверок хранятся семь дней.

Эта проверка подтверждает путь Cloudflare → GitHub и повтор только сохранения.
Она не включает автоматическое восстановление рабочих задач. Задача 7 остаётся
unverified, пока в её исходном workflow не появятся нужные гарантии.
