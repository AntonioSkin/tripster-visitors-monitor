# Мониторинг посетителей Tripster

Ежедневный сбор публичного счётчика «посетили» для шести выбранных экскурсий.

**[Последний отчёт](reports/latest.md)** · **[История CSV](data/daily.csv)** · **[Запуски](../../actions/workflows/daily.yml)**

Первый отчёт появится после успешного запуска GitHub Actions. До этого ссылки на данные могут возвращать 404.

## Расписание

Ежедневно в 08:15 по Алматы (03:15 UTC). GitHub Actions может запускаться с задержкой.
В публичных репозиториях GitHub может отключать расписание после длительного отсутствия активности; проверяйте вкладку Actions, если отчёты перестали обновляться.
Для ручного запуска: Actions → Daily visitors → Run workflow.

## Что сохраняется

- Число посетивших каждую экскурсию, время фактического чтения и ссылка.
- Общая сумма только при успешном сборе всех шести счётчиков.
- Изменение относительно предыдущей календарной даты; при отсутствии замера выводится «—».
- JSON каждого запуска в data/runs, ежедневные снимки в data/daily и таблица data/daily.csv.
- Ошибки помечаются явно и не заменяются нулями. Ошибочный повторный запуск не стирает успешный дневной снимок; последний отчёт показывает состояние последней попытки.

Скрипт открывает страницы непосредственно на Tripster через Chromium. Поисковые копии не используются.
Кэш браузера свежий для каждого запуска, отправляются заголовки no-cache; обновление на стороне Tripster остаётся под контролем самого сайта.
Счётчик привязывается к числу отзывов экскурсии, чтобы не перепутать его с общим счётчиком гида.
При неоднозначности скрипт завершится ошибкой. Защита сайта или изменения разметки могут потребовать доработки.
CAPTCHA и ограничения доступа скрипт не обходит.

Прирост счётчика не подтверждает фактическое количество посетителей за день. Итог — сумма посещений выбранных экскурсий, а не число уникальных людей. Уменьшения сохраняются как возможные корректировки Tripster.

## Экскурсии

Список находится в excursions.json: 51192, 54971, 57434, 96862, 55575, 53900.
Повторный запуск в тот же день обновляет дневной снимок, но все попытки остаются в data/runs.
Числа до первого запуска не восстанавливаются и не подставляются со скриншотов.

## Локальный запуск

Требуется Python 3.12.

```sh
pip install -r requirements.txt
python -m playwright install chromium
python -m unittest -v
python monitor.py
```

Рассылка в Telegram не настроена. Результаты доступны в этом репозитории.
