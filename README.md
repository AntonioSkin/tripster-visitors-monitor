Сбор счётчика «посетили» для экскурсий **51192, 54971, 57434, 96862, 55575, 53900, 85543**.

## Расписание
Ежедневно в **08:15 по Алматы** (03:15 UTC); возможны задержки GitHub Actions.
Ручной запуск: Actions → Daily visitors → Run workflow.

## Источник данных
Скрипт открывает публичную страницу каждой экскурсии в Chromium и читает ответ, который запрашивает сама страница: поле **visitors_count** в /api/web/v2/experiences/{id}/.
Проверяется ID экскурсии и тип счётчика. Общий счётчик гида не используется.
Отдельный запрос к API без контекста страницы возвращает 401, поэтому скрипт использует обычную загрузку страницы. Логин, скопированные токены и поисковые копии не используются.
Изменения сайта могут потребовать доработки. Данные актуальны на время ответа Tripster; внутреннее обновление счётчиков зависит от сайта.

## Отчёты
- По каждой экскурсии: число посетивших, время чтения и ссылка.
- Общая сумма выводится только при успешном сборе всех выбранных счётчиков.
- Прирост — разница с предыдущей календарной датой. «—» означает отсутствие сравнимого замера.
- Все попытки: data/runs. Ежедневные снимки: data/daily. Таблица: data/daily.csv.
- Ошибки не заменяются нулями; неудачный повтор не стирает успешный дневной снимок.
- Повторные успешные запуски в один день обновляют дневной снимок, но все попытки сохраняются.

Сумма — посещения выбранных экскурсий, а не уникальные люди. Прирост счётчика не подтверждает фактическое число посетителей именно за сутки. Уменьшения сохраняются как корректировки.

6 октября 2026 года сбор не удался: числового замера за эту дату нет. Значения со скриншотов задним числом не подставляются.

## Изменить список
Отредактируйте excursions.json. Не добавляйте одинаковый ID дважды.

## Локальный запуск
Python 3.12:
```sh
pip install -r requirements.txt
python -m playwright install chromium
python -m unittest -v
python monitor.py
```

Рассылка в Telegram не настроена. Результат доступен по ссылке «Последний отчёт».
Если обновления прекратились, проверьте Actions: GitHub может отключать расписания в публичных репозиториях при длительном отсутствии активности.
